# baustatik

## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues on `pYr0x/baustatik`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context — a root `CONTEXT-MAP.md` points to per-package `CONTEXT.md` files under `packages/*` and `apps/*`. See `docs/agents/domain.md`.
